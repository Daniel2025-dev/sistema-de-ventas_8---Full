# Sistema de ventas almacenes

Aplicacion de punto de venta desarrollada en Python con Flet y SQLite.

## Modulos principales

- Ventas y caja
- Cotizaciones
- Inventario
- Clientes
- Proveedores
- Pedidos
- Reportes
- Configuracion
- Usuarios

## Instalacion local

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Ejecucion

```bash
python3 index.py
```

## Notas

La base de datos local `database.db`, el entorno virtual y los documentos PDF generados no se versionan por seguridad y para mantener el repositorio liviano.
